# Weather Forecasting Data Lake — AWS

An end-to-end data lake pipeline built on AWS using S3, EMR, PySpark, and Cloud9 to ingest, clean, analyze, and visualize large-scale weather forecasting data. This project demonstrates real-world cloud data engineering, including navigating IAM permission constraints and compute limitations.

## Dataset

**Weather Forecasting Dataset** (Kaggle)

Operational logs from a real-world production weather forecasting system. Each record represents a forecast instance with features generated by climate and atmospheric models, including atmospheric pressure, cloud coverage, temperature estimates, humidity, precipitation, and other climate-related variables. The feature set is a curated subset from the Shift 1.0 Weather Forecasting Challenge.

## Pipeline Steps

### Step 1: Data Collection (`kaggle_on_loc_p1`)
- Authenticated download via Kaggle CLI
- Attempted multiple automated approaches (Kaggle → Cloud9 → S3) before settling on manual S3 upload due to IAM permission constraints

### Step 2: Cloud Infrastructure (`cloud9_p2`)
- Set up Cloud9 environment for running shell scripts
- Created S3 buckets and configured EMR cluster access
- Troubleshot IAM roles, credential errors, and permission blocks

### Step 3: Data Processing (`emr_p3`)
- Ran PySpark jobs on EMR for large-scale data processing
- **Data cleaning**: Normalized column names, handled missing values with mean imputation, created indicator flags for imputed values, removed duplicates
- **Outlier handling**: IQR-based detection and clipping to reduce influence of extreme anomalies
- **Standardization**: Numerical columns standardized for model training

### Step 4: Analysis & Visualization (`analyticsANDvis_p4` / `preview_analysis_viz`)
- **Descriptive statistics** and correlation analysis across all numeric features
- **Regression models**: Linear Regression and Random Forest Regressor to predict temperature from climate variables
- **Unsupervised learning**: K-Means clustering to identify interpretable weather patterns
- **Visualizations**: Correlation heatmaps, scatter plots with regression lines, cluster plots, missing-value structure heatmaps

## Key Challenges & Lessons Learned

### What Worked
- Data cleaning, preparation, and analysis stages ran smoothly once data was accessible
- Python/pandas/scikit-learn pipeline was effective for statistical analysis and ML modeling
- K-Means clustering revealed distinct weather regimes in pressure-temperature space

### What Didn't (And How I Adapted)
- **IAM Permission Errors**: AWS Academy Learner Lab restricted many automation features. Multiple approaches to automate Kaggle → S3 pipeline failed (`NoCredentialsError`, `KeyError`, permission blocks)
- **Compute Crashes**: Full parquet dataset caused repeated crashes during visualization. Adapted by using a preview subset for visualization while running analysis on the full dataset in EMR
- **Automated Pipeline**: Script accidentally generated several S3 buckets before failing. Ultimately used manual upload as recommended by professor

### Key Takeaway
Real-world data engineering isn't just about writing good code — it's about navigating infrastructure constraints, adapting when things break, and still delivering results.
